Dukungan Riap Daya

Bantuan untuk pencatatan sesi, cadangan data, kunci aplikasi, dan pembelian Versi Penuh.

Memulihkan Versi Penuh

Di Riap Daya, buka Pengaturan, lalu di bagian Versi Penuh ketuk Pulihkan Pembelian. Gunakan Akun Apple yang sama dengan saat membeli.

Mencadangkan dan memulihkan data

Buka Pengaturan → Data → Cadangkan Data, buat kata sandi minimal 8 karakter, lalu simpan file cadangan di tempat yang Anda pilih. File dienkripsi dengan kata sandi tersebut. Jika kata sandi hilang, file tidak dapat dibuka oleh siapa pun, termasuk pengembang.

Untuk memulihkan, buka Pengaturan → Data → Pulihkan Data, pilih file, lalu masukkan kata sandinya. Pemulihan mengganti semua data di perangkat. Kata sandi yang salah tidak mengubah apa pun.

Kunci aplikasi

Buka Pengaturan → Keamanan untuk menyalakan atau mematikan kunci dengan Face ID, Touch ID, atau kode sandi perangkat. Kunci tetap dianjurkan karena aplikasi menyimpan data klien.

Menghapus data

Untuk menghapus satu klien beserta program, target, sesi, dan catatannya, buka halaman klien, ketuk menu, lalu pilih Hapus Permanen. Menghapus aplikasi menghapus semua datanya dari perangkat. File cadangan, laporan PDF, dan file Excel yang pernah Anda simpan atau bagikan perlu dihapus dari tempat penyimpanannya.

Hubungi pengembang

Ajukan pertanyaan atau laporkan masalah di GitHub. Tulis versi aplikasi, versi iOS atau iPadOS, dan langkah untuk mengulangi masalah. Laporan GitHub dapat dilihat publik. Jangan sertakan nama klien, kode klien, diagnosis, catatan sesi, atau tangkapan layar yang memuat data klien.
