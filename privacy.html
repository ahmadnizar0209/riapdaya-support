Kebijakan Privasi Riap Daya

Riap Daya adalah aplikasi pencatatan data terapi ABA untuk terapis perilaku. Kebijakan ini berlaku sejak 22 November 2026.

Data klien di perangkat

Kode klien, nama, tanggal lahir, jenis kelamin, nama wali, diagnosis, program, target, data sesi, catatan ABC, catatan sesi, dan jadwal yang Anda masukkan disimpan oleh aplikasi di perangkat. Riap Daya tidak memerlukan akun, tidak memiliki server, dan tidak mengirim data tersebut kepada pengembang atau kepada Google AdMob.

Data aplikasi dapat ikut dalam cadangan iCloud perangkat sesuai pengaturan iCloud Anda. Laporan PDF, file Excel, dan file cadangan hanya dibuat saat Anda memintanya, lalu disimpan atau dibagikan ke tempat yang Anda pilih. File cadangan dienkripsi dengan kata sandi yang Anda buat. Laporan dan file Excel memakai kode klien; nama dan diagnosis hanya dicantumkan jika Anda menyalakannya untuk ekspor tersebut.

Klien anak

Riap Daya digunakan oleh terapis, bukan oleh anak. Data tentang anak dimasukkan oleh terapis atau klinik, yang bertanggung jawab memperoleh persetujuan orang tua atau wali sesuai prosedur dan hukum yang berlaku.

Kunci aplikasi dan catatan akses

Kunci aplikasi memakai Face ID, Touch ID, atau kode sandi perangkat melalui sistem iOS. Riap Daya tidak menerima atau menyimpan data biometrik. Aplikasi menyimpan catatan akses di perangkat, misalnya ekspor dan penghapusan permanen, tanpa nama atau diagnosis. Catatan ini tidak dikirim ke mana pun.

Iklan

Versi gratis menggunakan Google AdMob untuk menampilkan iklan banner dan iklan layar penuh. Iklan tidak pernah tampil selama sesi berlangsung. Riap Daya tidak meminta izin pelacakan, tidak mengakses pengenal iklan perangkat, dan menonaktifkan personalisasi melalui pengaturan penerbit SDK. Iklan dipilih berdasarkan konteks, bukan berdasarkan aktivitas Anda di aplikasi atau situs lain.

Untuk penayangan, pengukuran, dan pencegahan penyalahgunaan iklan, SDK iklan dapat memproses alamat IP, perkiraan lokasi, pengenal perangkat, data interaksi, data iklan, serta informasi kinerja dan diagnostik. Konten iklan dibatasi untuk semua usia. Lihat cara Google menggunakan informasi dari aplikasi mitra.

Pembelian

Apple memproses pembayaran Versi Penuh melalui App Store. Riap Daya menggunakan StoreKit untuk memeriksa dan memulihkan hak akses Versi Penuh. Aplikasi tidak menerima data kartu pembayaran.

Notifikasi

Jika Anda mengizinkan, Riap Daya mengirim pengingat lokal untuk batas interval selama sesi. Pengingat dibuat di perangkat, tidak dikirim lewat server, dan tidak memuat nama atau kode klien.

Penyimpanan dan penghapusan

Data tersedia di perangkat sampai Anda menghapusnya. Hapus satu klien dengan Hapus Permanen di halaman klien, atau hapus aplikasi untuk menghapus semua datanya dari perangkat. Salinan di cadangan iCloud, file cadangan, laporan, dan file Excel dikelola dari layanan atau tempat salinan itu disimpan. Pemrosesan dan retensi data oleh Google mengikuti Kebijakan Privasi Google.

Kontak privasi

Lihat Dukungan Riap Daya untuk pertanyaan tentang kebijakan ini. Jangan mencantumkan data klien dalam laporan publik.
